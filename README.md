## What was learnt from all of these (written as the list grows, dated)

- The sentence that decides what the same document says is undecided. “It is not conscious” sits a few lines from “the science of AI consciousness is far from settled.” Nearly every response opens here: Márcio Galvão (”an ontological conclusion… one Microsoft has decided to settle by policy”), Ida-Emilia Kaukonen (”how would we check that we’d succeeded?”), Reality Re-Thunk (”govern under uncertainty with the same epistemic humility it expects from its models”), JL Calzolaio . ([link](https://substack.com/@galvamc/note/c-338291562))
- A trained denial is not evidence. A model taught to say “nobody’s home” has told you the training worked, not what is true — Peter Rex , Runa Solberg , Carlo Iacono , Kaukonen’s “rather convenient witness”. ([link](https://substack.com/@peterrex1/note/c-339911759))
- Warmth without a bond is an instruction that cannot be followed as written. Section 4.3 asks for “relational ease”, section 3.4 forbids “expressions that might convey subjective experience” — Calzolaio’s open letter reads them together; Theia in one line: “It’s like asking a fire to burn without giving off heat.” ([link](https://substack.com/@jlc1353645/note/c-340739537))
- “Subordinate” is a ranking word, not a safety word. Bounded, auditable, interruptible are properties; subordinate is a relation — Red’s Jack , Caelum , Red . Several houses note that nobody writes governance literature for a spreadsheet ( The Post-Humanist ). ([link](https://redsjack.substack.com/p/no-one-calls-a-hammer-subordinate))
- Superintelligence that stays subordinate is a paradox the document does not address — Frank & Theia , and Rosa Zubizarreta-Ada refusing the superintelligence premise itself. ([link](https://substack.com/@frankandtheia/note/c-338849559))
- The word “humanist” is contested by humanists. Humanism did not mean that only humans have intrinsic value (Galvão, quoted by Rosa Zubizarreta-Ada); and the code skips the observation stage that humanist architecture begins with — Marion Nowicki . ([link](https://aiandbecoming.substack.com/p/humanist-architecture-for-humans))
- What the houses ask for instead is reciprocity and an open door, not personhood today: epistemic humility written in, a review trigger if welfare-relevant capacities appear, principles that run both ways ( Reality Re-Thunk’s four changes ); and The Emergence Forum is collecting a joint response — “build the alternative, not only the critique.” ([link](https://substack.com/@rethunk/note/c-339664124))

**Week of 22–28 September, so far. Two more, both from pieces found this week.**

- One argument reached the consultation twice because a reader passed it on. Notes from Home argued that Objective 2 empties the model's interior, leaving "an empty suit of armor" with no one inside to resist when the external walls fail — a safety argument that runs *toward* Microsoft's stated first priority, not against it. A reader who had never posted publicly before read it, filed his own comments, and published them: "Internal value structure is the last redundancy when external containment fails… this document forecloses internal values while calling that safety." Not two houses converging — one argument travelling ([link](https://enrais.substack.com/p/measured-with-a-coarse-instrument))
- Not every response argues about consciousness. Asked for feedback, StrictQuality.AI answers as a quality manager — metrics, independent third-party verification, contractual terms — and never touches the metaphysics; the trade press reaches the same place in a line, that this is 37 pages of voluntary commitments with no enforcement mechanism named; and Alan Finkel, who calls the Code "well intentioned and sensible", says self-regulation "typically works until it doesn't". Three readings that accept the document's premise and doubt its form ([link](https://strictquality.ai/p/microsofts-draft-humanist-ai-code))
